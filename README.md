# Courses App

## Prerequisites

- **Node.js** (v14 or later)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/sincerelyyyash//course-app.git
cd /course-app
```
### Install Dependency
```bash
npm install
```

### Run the Development Server:
```bash
npm run dev
```

- Visit http://localhost:3000 in your browser to see the application in action.
